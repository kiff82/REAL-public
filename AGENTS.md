# Agent Guidance for the Public Seed

This repository is the bounded public surface of REAL.

## Non-negotiable project identity

- REAL is the coupled contact system: frozen manifold plus an
  input-conditioned dynamic head.
- The head is not a second mind, replacement model, planner, or persistent
  memory.
- Backbone weights remain frozen.
- StaticPrefix is a serious falsification baseline.
- Four updates mean five states, `z0..z4`, with generation committed from `z4`.
- Probes and aggregate rows measure contact; they are not the contact system.

## Public-release boundary

Do not add raw datasets, benchmark rows, checkpoints, model shards, notebook
outputs, private paths, credentials, sealed evidence, or private handovers.
Heartbeat is a graduated support substrate and is not to be copied into this
seed as REAL runtime.

## Claims discipline

- Lead with the bounded contact-system question.
- Keep Hotpot contract stability separate from insufficiency-contact objective
  results.
- The insufficiency objective remains `not_promoted_local_only`.
- Heartbeat is separate and excluded; do not import it into REAL or infer a
  model-facing claim from it.
- Do not claim general reasoning, grounding, reliable abstention, authority,
  consciousness, agency, or alignment from this repository.

## Development lineage

Preserve the README's attribution to the sustained kiff–ChatGPT/Codex
collaboration. Treat it as project provenance, never as empirical evidence or
model authority. Kiff owns the repository and the release decision.

## Required maintenance

When code, claims, or evidence change, update the README, release status,
evidence index, reproducibility boundary, and release manifest together. Run
the release audit and tests before proposing publication.
