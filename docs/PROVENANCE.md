## Exclusions

The source repository's history and other branches are not parents of this
release. Large result banks, raw/per-example evidence, historical handovers,
notebooks, local paths, model/checkpoint artifacts, and Heartbeat implementation
were excluded before the clean initial commit.

REAL's development lineage includes sustained collaboration between kiff and
ChatGPT/Codex systems. That provenance is preserved in the public README while
all scientific claims remain evidence-bound.

`RELEASE_MANIFEST.json` binds the exact files in the prepared seed.
