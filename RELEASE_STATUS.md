# Public Release Status

This file is the claims boundary for the REAL public seed dated 2026-08-29.

## What is released

- the contact-system concept and research contract
- the model-facing implementation skeleton
- base/static/REAL comparison interfaces
- a network-free structural demonstration
- selected aggregate evidence without benchmark source rows
- release-audit and manifest tooling

## Strongest allowed claim

REAL is an experimental method for testing whether a small input-conditioned
head can change access to and stability within a frozen language model's latent
structure, relative to matched base and fixed-signal comparisons.

The checked-in results show scoped behavioral and trajectory differences on
particular checkpoints and diagnostic lanes. They do not establish a general
mechanism across models, tasks, or deployment settings.

## Current scientific state

### Model-facing REAL

- The canonical cue-aligned Hotpot lineage has a visible local apex at
  checkpoint `73000` relative to `72000` and `73600`.
- That lane is evidence of contract-completion and trajectory shape under a
  forced scaffold. It is not proof of general reasoning or factual grounding.
- The insufficiency-contact objective is locally responsive but did not improve
  the matched held-out false-certainty contact branch.
- Its closeout remains `not_promoted_local_only` at evidence level
  `manifold_contact_observed`.

### Exact historical reproduction

Exact replay remains blocked because the public seed does not contain the three
historical REAL/static checkpoints or the exact frozen-backbone shards. No
public execution package is claimed from omitted artifacts.

### Heartbeat

Heartbeat is a separate, graduated support substrate—not REAL and not a runtime
layer in this public seed. Its implementation and evidence banks are excluded,
and no Heartbeat result creates a model-facing claim for this release.

## Explicit non-claims

This repository does not claim that REAL:

- is AGI, ASI, conscious, agentic, or a second mind
- is an autonomous planner or tool user
- has persistent or cross-call memory
- modifies, repairs, teaches, or updates the frozen backbone
- makes a model reliably know when it does not know
- solves hallucination, reasoning, grounding, or alignment in general
- has earned deployment authority or control over model outputs
- reproduces the included aggregate results without the omitted artifacts

## Reproduction boundary

The code is inspectable and new experiments can be run. Exact historical
reproduction remains blocked because the public seed includes neither the
historical checkpoints nor the exact backbone shards. Claims derived from new
runs must carry their own model revision, dataset version, sample universe,
checkpoint identity, seeds, evaluation protocol, and base/static/REAL results.

## Development provenance

The project emerged through sustained collaboration between kiff and
ChatGPT/Codex model lineages. This is development provenance, not empirical
support for the method and not a transfer of release authority.
